## About the Series

**Avatar: The Last Airbender** is an animated fantasy series that aired on *Nickelodeon* from 2005 to 2008. It was created by Michael Dante DiMartino and Bryan Konietzko.

## Quick Facts

| Detail        | Info                  |

| Episodes      | 61                    |
| Network       | Nickelodeon           |

## Main Characters

1. **Aang** - the last Airbender and the Avatar
2. **Katara** - a Water Tribe waterbender
3. **Sokka** - a warrior and strategist
4. **Toph** - the greatest earthbender
5. **Zuko** - the exiled Fire Nation prince
